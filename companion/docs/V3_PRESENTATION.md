# V3 native presentation candidate

V3 preserves the V2 core, native grants, account partitions, task confinement,
Snooze visibility and immutable version recovery. The renderer remains native
Quickshell/Qt Quick. No provider call is made by the motion director or cursor
reader.

The 48-entry motion catalogue currently contains 41 authored numeric sequences
and seven explicit matching-view gaps. A numeric sequence is not a visually
approved animation. `MotionReview.qml` provides pause, scrub, seeded coverage,
expression and size controls. The eight expressions use authored face controls
on the original character. Original character media stays outside Git.

`Motion.js` owns channel limits, monotone curves, articulated joint transforms,
C1 interruptions and novelty history. `Actor.qml` runs one visible clip at a
time; quiet, reduced motion and hidden states stop its frame loop. The live
transformed silhouette is always included in the native surface during a
handover. Alpha-derived input regions move with the same part matrices.

`capri.pointer` reads the owned Hyprland Unix socket, samples at at most 8 Hz
while moving and backs off to 1 Hz at rest (up to 4 seconds after failures).
Only whitelisted output geometry and an ephemeral point reach the UI. The
reader records no trace, reads no keys, injects no input and never talks to the
core/provider. Output-local mapping accounts for negative origins, rotation,
compositor scale and per-app Qt dimensions. Loss and output changes cancel a
pending approach. Owner input, quiet/pin/reduced motion and speech take priority.

Talk, Activity and Settings retain the actual model/account, task scope,
commands, Stop, native scope decision and immutable proposal review controls.
Alt+1/2/3 changes panes; Ctrl+F finds text; Ctrl+. stops work. The composer uses
the existing persistent draft owner. Activity reads a bounded partition-owned
journal projection and cannot widen a grant.

New appearance preferences live in `presentation-profile-v3`, separate from the
strict V2 profile. V2 rollback can still load its profile unchanged. Text size
ranges from 100 to 200 percent. Roam and cursor curiosity are distinct controls.

The palette and 26-pixel native surfaces adapt the inspected portfolio source
at `Denoax/portfolio@4da21a826aa850621df897e07b46600b24499cf2`. Navigation keeps
Inter Medium 14-pixel rhythm and joined selection. Rare UI attribution is in
`Rare-UI-NOTICE.txt` and Settings. No portfolio hero or web runtime is embedded.

Use the existing per-app `--render-backend software|rhi` fallback. Resource
qualification retains the 2-percent one-core CPU and 250-MiB summed RSS targets;
a completed measurement is not a resource pass. Native frame/capture evidence,
physical-device limits and human motion approval are recorded separately in the
source-bound local review packet. Installation and a testing-branch push do not
constitute human artistic acceptance or main/release integration.
