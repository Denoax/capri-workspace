## Rebuild

Use the recorded presentation environment (Python, Pillow, NumPy, websockets), FFmpeg and Chromium. Set `CAPRI_CHROMIUM` when needed. Runtime dependencies/locks, controllers and CI policy are unchanged.

```sh
python3 tools/build_capri_story.py
python3 tools/export_capri_story.py --evidence /your/task-private/media-evidence
python3 tools/build_capri_story_readme.py
python3 tools/build_capri_source_match_manifest.py
python3 tools/check_capri_presentation.py
python3 tools/check_capri_graph_browser.py --evidence /your/task-private/graph-check
```

The exporter samples actual source clocks, records every frame's identity and full-body alpha bounds, and rejects nonuniform scaling or clipping. Decoded cadence/distinct states, source/data/dimension reproducibility and exact native bytes remain separate. All files stay below8,000,000 bytes. Original large references retain verified chunk storage and materialize outside the runtime checkout.

Recorded loops, selected images, browser checks and CI do not establish uninterrupted perceived smoothness, human visual acceptance, hosted-GitHub behavior, physical devices or GPU timing. Actual measurements and unavailable checks remain explicit in the review.
